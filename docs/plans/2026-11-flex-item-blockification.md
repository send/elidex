# Compute item display before publishing style

PM 1087 advances C1b.2-pre to 3b.2-pre, after 3b.2 and before the standalone Flex write-retirement PR. Its style producer runs on the current computed-style types. The Flex collector currently changes the item's display and reinserts its entire computed style. The shared child dispatcher reads that display when deciding whether an auto-width inline container needs shrink-to-fit. Move the computed-display decision to style resolution so both pre-layout readers and the first child dispatch see the same value.

## §1. Carry the effective ancestor through style resolution

Start the document walk with no effective ancestor. Carry the nearest flat-tree ancestor element's finalized display separately from the immediate inheritance parent's style. A document or shadow root introduces no element display. Derive child context from the finalized local value: ordinary Contents forwards the incoming ancestor, while every other display, including None, starts a new context. Restore the caller's context at each sibling.

Finalize each local style once. Supply the implicit inline display for generated before/after during default selection, so explicit winners and inheritance participate normally. Give the producer element identity and document-element status to resolve applicable contents fixups, including the HTML unusual-element rules and the document element's Contents-to-Block conversion. In the shared adjustment sequence preserve the position/float rules (including the absolute/fixed float reset) and use Display::blockify for qualifying effective parents Flex, InlineFlex, Grid and InlineGrid. Remove the late pseudo default assignment in pseudo.rs. Publish the finalized local style, pass that same value to pseudo generation and descend with it as the inheritance parent. Anonymous text items receive no element style adjustment. Repeat from the cascade on restyle. [CSS 2 §9.7](https://www.w3.org/TR/CSS22/visuren.html#dis-pos-flo) · [CSS Display Appendix B](https://www.w3.org/TR/css-display-3/#unbox-html) · [CSS Display §2.8](https://www.w3.org/TR/css-display-3/#root)

Share the walk continuation after node resolution across ordinary, shadow and assigned nodes. Resolve an assigned host with its applicable slotted and host cascade inputs. Using its finalized style, distribute slots and descend through its own shadow root with the applicable shadow sheets. Visit fallback children only for an unassigned slot. Preserve inherited and effective-display contexts across return to ordinary siblings. Layout consumes the published display without an ancestor lookup.

Flexbox §4 and Grid §6.1 define the ancestor predicate even for a parent that generates no container box. CSS Display §2.7 defines the conversion, including table-internal and box-suppressing values. [Flex items](https://www.w3.org/TR/css-flexbox-1/#flex-items) · [Grid item display](https://www.w3.org/TR/css-grid-1/#grid-item-display) · [Automatic box type transformations](https://www.w3.org/TR/css-display-3/#transformations)

| Crossing | Production route | Required observation |
|---|---|---|
| Contents × auto-width inline-flex | Author stylesheet → style walk → ECS → dispatch_layout_child | Use a 200px column Flex with two contents wrappers and an auto-width inline-flex child containing a fixed 20px descendant. Before any layout the child computes to Flex, width Auto, and inherits the inner wrapper's distinct color. At the initial auto-width dispatch observe the Flex route, the incoming width and absence of the inline shrink-to-fit adjustment. Final stretch gives 200px. A normal block ancestor inserted between wrapper and item restores InlineFlex on restyle and the ordinary auto-width dispatch shrinks to 20px. Inspect the branch on dispatch before any placement override can mask it. |
| Inheritance × restyle | Flex → inline item → child with explicit display:inherit | Read both ECS styles before any layout. Switching the outer container from flex to block and back gives Block/Block, Inline/Inline, Block/Block. A sibling branch with an intervening ordinary block retains Inline. |
| Assigned host × shadow descent | Slot → assigned host styled Flex → inline-flex shadow child | Observe Flex on the shadow child before layout and InlineFlex after restyling the host to block. An ordinary sibling under a block context retains InlineFlex in both passes. In a separate fixture, an assigned inline leaf inherits its contents slot’s distinct color and computes to Block under Flex. Under an ordinary block, an empty contents slot’s inline fallback inherits that slot’s color and computes to Inline. |
| Pseudo defaults × ordered adjustment | Generated content under block and contents origins | With generated content and omitted display, an absolute ::after under block and a static ::before on a contents origin under Flex both compute to Block before layout. A static, un-floated pseudo under an ordinary block computes to Inline. |
| Element identity × contents | Style walk → descendant context | Under Flex, an ordinary contents wrapper retains Contents and its inline child computes to Block. A canvas with the same declaration computes to None and its inline fallback child stays Inline. At the document entry, html with display:contents computes to Block and its inline child stays Inline. |
| Grid and hidden-subtree siblings | Grid and Flex style publication | A table-cell child under InlineGrid computes to Block. A Flex parent below a hidden ancestor still yields Flex for its inline-flex child. A child declared none retains None. |
| Collection × placement ownership | Style producer → collect_flex_items → relayout_item_at_position | In this prerequisite assert pre-layout display and the collector's display predicate is already satisfied. Keep both existing writes at the producer landing.
