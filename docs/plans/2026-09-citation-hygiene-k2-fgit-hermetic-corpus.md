- **What counts as a kill.** `_mut_trial` counts a record killed only where its needle stands in a diagnostic's label
  slot: `CONTROL FAILED (<needle>)` or `CONTROL NOT EXERCISED (<needle>)` (the `!kill` arm's `CONTROL FAILED` form, plus `CONTROL NOT EXERCISED`). A label that is
  printed on a green summary line therefore cannot let an unrelated red kill a record (K15, R7.13). Since the pre-push gate's fix round, never through `_ctl_run`'s watchdog line (`CONTROL FAILED (<label>): the wire did not finish — killed after Ns`), which says only that the run blocked: both arms read the output without those lines, so a run whose only red is a timeout is reported (wrong subject, or wrong reason), not counted as killed (review A4-1). The consequence: a future record that pins a hang, whose only evidence is that watchdog line, cannot be killed as named; it is reported killed by the wrong subject or for the wrong reason, a red, never a survivor counted killed (the fail-safe direction), and such a record needs a needle the hang's own check prints.
