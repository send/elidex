# Resume inline content across pages of different widths

3b.2 owns the shared source cursor for binding F3. The adopted umbrella at d1bff8b6 assigns source progress to L1. 3b.1 supplies selected geometry. 3b.3 will replay page identities and break events. PM 1009 assigns Flex to 3b.2f. PM 1010 assigns Grid to L1 in 3b.2g and closes the Block, Flex, Grid and Multicol audit.

## §1. Continuation state

BreakTokenData::Block currently carries a child index and an optional count of already emitted lines. Both block/mod.rs and the mid-run and trailing-run paths in block/children/stack.rs pass that count to the inline formatter. inline/mod.rs packs the entire run at the new width, then slices by the old line count. A page change can place different words before that count.

Use one representation of progress throughout inline, Flex and Grid: a set of consumed source intervals keyed by formatting-context owner and stable source item. Within an item use half-open intervals in its logical source sequence. Include an end-of-item boundary so that completion of an empty or nonpainting item is representable. Initially the set is empty. Commit only the intervals actually consumed at the chosen break and coalesce adjacent intervals of the same item. A continuation advances by covering a previously uncovered interval or its item's terminal boundary. A tentative line, placement or balancing probe cannot advance the definitive token. On resume consume the complement in the new layout. Inline prefix progress takes one interval within a text item; Grid can finish B while A and C remain untouched. A spanning child can have partial coverage alongside another finished item. Preserve this state for a single immutable input snapshot. Start with empty coverage on DOM or style changes.

Carry source coordinates through collection, whitespace processing, transformation, shaping and line commitment. For collapsed whitespace spanning text nodes retain the contributing source ranges. For an expansion retain the item identity, valid source boundary and position within its deterministic transformed sequence when it admits multiple breakable units. Identify atomic and generated items in their owner's logical input. Commit at supported cluster boundaries after widow/orphan adjustment. Restore language, shaping and bidi context on resume. Consumed content contributes zero advance to the fresh line, including when the new width would otherwise place the old prefix and new suffix on the same line. Preserve L2's line and transformation semantics.

Give the Block token three explicit alternatives. A **local run continuation** carries run identity and consumed intervals on the owning block or mixed stack. Both mid-run and trailing-run flushes produce this alternative. An **interrupted child** identifies the current child and carries its nested token. A **child boundary** identifies the next child for ordinary sibling resumption. Match these alternatives in stack and Multicol. Route local runs directly to the formatter, nested tokens to the identified child, and child boundaries to the next child. Only an interrupted child selects the spanning-child snapshot/shift path. Preserve whole-column persistence for a complete run. The counting and paint layout passes each start from the same immutable input progress and geometry; capture their results before per-entity output is overwritten.

## §2. Crossing checks

| Crossing | Producer → consumer | Discriminating observation |
|---|---|---|
| Source boundary × geometry | Committed line → next-width formatter | Use four equal-width words A–D, simple LTR, deterministic metrics, one line per page and widows/orphans of one. Size the narrow line for one word and the wide line for two including the space. Narrow→wide→wide must emit [A], [B C], [D]; wide→narrow→narrow must emit [A B], [C], [D]. On every page the first word begins at inline offset zero from the content origin. Check the expected groups and first-word positions separately on the count and paint layout passes. Retain a constant-width control. |
| Source boundary × run kind | Collector and packer → direct and mixed block consumers | Repeat with multiple text nodes, a nested inline, an atomic item, a transformed character, collapsed whitespace and an empty decorated inline. Verify source coverage and atomic identity across an inline run followed by a block and a trailing inline run. Use L2’s existing semantics as inputs. |
| Geometry × replay | Count pass → per-page layout pass | With the same start cursor and width, compare each pass against the expected consumed interval set, emitted group and positions, then compare the two outputs. Check termination and total pages against emitted fragments. An updated snapshot must begin at the initial cursor. |
