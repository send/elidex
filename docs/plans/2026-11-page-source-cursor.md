## §1. Continuation state

BreakTokenData::Block currently carries a child index and an optional count of already emitted lines. Both block/mod.rs and the mid-run and trailing-run paths in block/children/stack.rs pass that count to the inline formatter. inline/mod.rs packs the entire run at the new width, then slices by the old line count. A page change can place different words before that count.

Use one representation of progress throughout inline, Flex and Grid: a set of consumed source intervals keyed by formatting-context owner and stable source item. Within an item use half-open intervals in its logical source sequence. Include an end-of-item boundary so that completion of an empty or nonpainting item is representable. Initially the set is empty. Commit only the intervals actually consumed at the chosen break and coalesce adjacent intervals of the same item. A continuation advances by covering a previously uncovered interval or terminal boundary, or by advancing the box’s specified-size fraction while its remaining source is empty. A tentative line, placement or balancing probe cannot advance the definitive token. On resume consume the complement in the new layout. Inline prefix progress takes one interval within a text item; Grid can finish B while A and C remain untouched. A spanning child can have partial coverage alongside another finished item. Preserve this state for a single immutable input snapshot. Start with empty coverage on DOM or style changes.

Carry source coordinates through collection, whitespace processing, transformation, shaping and line commitment. For collapsed whitespace spanning text nodes retain the contributing source ranges. For an expansion retain the item identity, valid source boundary and position within its deterministic transformed sequence when it admits multiple breakable units. Identify atomic and generated items in their owner's logical input. Commit at supported cluster boundaries after widow/orphan adjustment. Restore language, shaping and bidi context on resume. Consumed content contributes zero advance to the fresh line, including when the new width would otherwise place the old prefix and new suffix on the same line. Preserve L2's line and transformation semantics.

Give the Block token three explicit alternatives. A **local run continuation** carries run identity and consumed intervals on the owning block or mixed stack. Both mid-run and trailing-run flushes produce this alternative. An **interrupted child** identifies the current child and carries its nested token. A **child boundary** identifies the next child for ordinary sibling resumption. Match these alternatives in stack and Multicol. Route local runs directly to the formatter, nested tokens to the identified child, and child boundaries to the next child. Only an interrupted child selects the spanning-child snapshot/shift path. Preserve whole-column persistence for a complete run. The counting and paint layout passes each start from the same immutable input progress and geometry; capture their results before per-entity output is overwritten.

### Low-level continuation lifetime (PM 1084)

A new paged run starts with empty progress. Direct layout dispatch can resume only within the same immutable source and computed styles. The positive control is the interleaved builder, which stores counting-pass tokens in a local vector and borrows them during replay in the same call. The public fragmented-layout driver starts its local chain at None. Block, Flex, Grid and Table consume input from their invoking layout pass, and Multicol owns its carry in a single fill invocation. Geometry generation changes on individual paint pages and cannot identify an input snapshot.
