## §1. Trace an item from collection to its final child callback

**Collect and measure.** Consume the computed display published by the C1b.2-pre producer. Remove the collector's blockification write in helpers.rs and the preferred-size writes in position.rs together. Remove the min-probe descendant style save/restore once both Grid and Flex paths preserve computed style. Inventory equivalent snapshot callers and retain their independent behavior. Measure with the actual min- and max-content inputs. The 1px min-probe width and the max probe's available width constrain the algorithm. Select a percentage reference independently per physical axis and phase. When the grid area depends on the contribution, resolve cyclic percentages in margins and padding against zero for that contribution. Preserve definite references on axes already established. Use the property's intrinsic rules for cyclic preferred sizes. Auto margins contribute zero in track sizing. [CSS Sizing §5.2.1](https://www.w3.org/TR/css-sizing-3/#cyclic-percentage-contribution) · [CSS Grid §11.2](https://www.w3.org/TR/css-grid-2/#auto-margins)

Build each axis's min/max outer contribution from that individual measured content box plus its own physical padding, borders and margins once. Retain the two results independently before the next callback. Replace the shared item.pb and item.margin reads in build_contributions and the subgrid first/last-track edge additions with the corresponding phase's data. Preserve span and subgrid-axis mapping, inherited tracks and applicable gaps. Inventory the intrinsic sizing entry alongside measure_item_content so track sizing and shrink-to-fit contributions agree for the same request.

**Resolve the area and place the item.** For the baseline pass, the preliminary height measurement and final placement in position.rs, rebuild the invocation from the current area's physical rectangle and writing mode. Resolve percentage preferred width and height against their respective area axes, and percentage edges against the area's inline size before margins. Subtract each edge once according to box sizing. Give preliminary measurement only the content axis already assigned and the actual space for the remaining axis. Compute baselines from that measurement's box and edges. Use the final content pair and all four used margins, including assigned zeros, at the common receiver before laying out descendants. Auto margins absorb positive free space before self-alignment, or resolve to zero on overflow. Return the child's actual box, baseline and fragment outcome. Retire the final style reinsertion and any outer-box size correction masking an incorrect child input. [CSS Grid §6.4](https://www.w3.org/TR/css-grid-2/#item-margins) · [Grid item sizing](https://www.w3.org/TR/css-grid-2/#grid-item-sizing)

**Carry gutters across the sizing boundary.** In lib.rs distinguish the gap used in intrinsic size contributions from the one used to lay out contents. For a cyclic percentage use zero in intrinsic sizing, establish the grid's own content size, and then resolve the definitive gap against that content axis. Keep the established content size when the resulting tracks and gutters overflow it. Feed definitive geometry into positions, alignment, area spans, inherited subgrid gaps and fragmentation. Preserve collapsed gutters and suppression across fragment breaks. A definite noncyclic percentage gutter can resolve during sizing. Apply the same axis selection to columns and rows. [CSS Gaps §2.3](https://drafts.csswg.org/css-gaps-1/#gap-percent) · [CSS Grid §11.1](https://www.w3.org/TR/css-grid-2/#gutters)
