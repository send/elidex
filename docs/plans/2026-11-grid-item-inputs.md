# Resolve Grid item inputs for each measurement and placement

C1b.3 follows [C1b.2](2026-11-flex-item-inputs.md) at cf09dd05 (#742). It supplies the Grid side of C1b binding F1, the contribution and placement evidence for F2, and the intrinsic-to-definitive gap evidence for F4. Use the existing Dimension variants and C1b.1’s separate physical reference rectangle, containing writing mode and algorithmic available space. C1b.2 provides the common receiver for assigned content axes, used edges and an unshifted margin-box origin.

## §1. Trace an item from collection to its final child callback

**Collect and measure.** Consume the computed display published by the C1b.2-pre producer. Remove the collector's blockification write in helpers.rs and the preferred-size writes in position.rs together. Remove the min-probe descendant style save/restore once both Grid and Flex paths preserve computed style. Inventory equivalent snapshot callers and retain their independent behavior. Pass an explicit min-content or max-content constraint and requested axis on each intrinsic measurement invocation. Both normal Grid track sizing and the Grid shrink-to-fit entry request the same formatter measurement. A numeric probe width alone cannot select either constraint. Select a percentage reference independently per physical axis and phase. When the grid area depends on the contribution, resolve cyclic percentages in margins and padding against zero for that contribution. Preserve definite references on axes already established. Use the property's intrinsic rules for cyclic preferred sizes. Auto margins contribute zero in track sizing. [CSS Sizing §5.2.1](https://www.w3.org/TR/css-sizing-3/#cyclic-percentage-contribution) · [CSS Grid §11.2](https://www.w3.org/TR/css-grid-2/#auto-margins)

Route inline intrinsic requests through the existing layout/intrinsic dispatcher via the parent-supplied formatter callback. Expose its content measure before its outer wrapper adds inline padding and border. Factor this boundary across explicit/replaced, empty and recursive formatter branches. Existing intrinsic callers still receive their edge-inclusive result. Grid's contribution builder takes the requested content measure and adds the phase-resolved padding, border and margin exactly once. A block containing text uses the existing inline measurement of the runs. Preserve each min/max result before the next callback. [CSS Sizing §5.1](https://www.w3.org/TR/css-sizing-3/#intrinsic-sizes)

Build column contributions first and size the columns (or take inherited tracks). For each row measurement, map the item's column span to its resolved inline extent, including internal effective gutters and collapsed tracks. Lay out the item at that inline geometry to determine its block contribution, resolving percentage edges against that span. Size the rows from these new contributions. On a subsequent axis pass prescribed by the sizing algorithm, rebuild affected invocations whenever the opposite-axis span, gutters, available space, constraint or definiteness changes. After a column change refresh the dependent row measurements before final positions. Preserve subgrid track inheritance and writing-mode mapping. [CSS Grid §12.1](https://www.w3.org/TR/css-grid-2/#algo-grid-sizing)

On a subgridded axis, project descendant contributions into parent track coordinates using their placed start and span. The boundary producer adds the subgrid's phase-resolved start/end margin, border and padding as an extra layer on the affected descendant contribution, using its parent-track address. At an empty boundary of a non-empty subgrid, the same producer searches inward to the closest occupied track. For each distinct item span there, select the largest relevant contribution for the current measurement, add the boundary inset once, and extend the selected span across the intervening empty tracks to that boundary. Emit the full hypothetical contribution with its extended start and span in parent coordinates. Apply this rule from either end. Map both edges to the same track for a one-track span. Nested levels each charge their own layer once. The ordinary contribution builder owns the item's outer edges on an independent axis. Remove the item-vector indexing by track ordinal in add_subgrid_axis_mbp. [CSS Grid §9](https://www.w3.org/TR/css-grid-2/#subgrids)

**Resolve the area and place the item.** For the baseline pass, the preliminary height measurement and final placement in position.rs, rebuild the invocation from the current area's physical rectangle and writing mode. The shared invocation builder resolves each phase's preferred-size state and edges once: preferred percentages use the corresponding area axis and percentage edges use its inline size before margins. Grid stretch/fit consumes those resolved states and edges, and dispatch carries the same values with the resulting assignments. Remove position.rs’s resolve_item_dimension evaluator from the path. Keep definite zero, auto and a still-unresolved percentage distinguishable until the phase selects measurement or assignment. Preserve baseline and fragmentation callbacks independently of a definite preferred axis. Subtract each edge once according to box sizing. Give preliminary measurement only the content axis already assigned and the actual space for the remaining axis. Compute baselines from that measurement's box and edges. Use the final content pair and all four used margins, including assigned zeros, at the common receiver before laying out descendants. Auto margins absorb positive free space before self-alignment, or resolve to zero on overflow. Return the child's actual box, baseline and fragment outcome. Retire the final style reinsertion and any outer-box size correction masking an incorrect child input. [CSS Grid §6.4](https://www.w3.org/TR/css-grid-2/#item-margins) · [Grid item sizing](https://www.w3.org/TR/css-grid-2/#grid-item-sizing)

**Carry gutters across the sizing boundary.** In lib.rs distinguish the gap used in intrinsic size contributions from the one used to lay out contents. For a cyclic percentage use zero in intrinsic sizing, establish the grid's own content size, and then resolve the definitive gap against that content axis. Keep the established content size when the resulting tracks and gutters overflow it. Feed definitive geometry into positions, alignment, area spans, inherited subgrid gaps and fragmentation. Preserve collapsed gutters and suppression across fragment breaks. A definite noncyclic percentage gutter can resolve during sizing. Apply the same axis selection to columns and rows. [CSS Gaps §2.3](https://drafts.csswg.org/css-gaps-1/#gap-percent) · [CSS Grid §11.1](https://www.w3.org/TR/css-grid-2/#gutters)
