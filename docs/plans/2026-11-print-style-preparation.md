# Prepare print style from the selected first page

G′a-geo 3b.1, PM 1007/1008. This child follows T, G and the render builder split. It supplies prepared style inputs to 3b.2 and 3b.3. Its public-path acceptance ends at document computed style and the selected geometry supplied to layout. 3b.3 owns the break events that establish page identity and blankness. 3b.4 owns verification of the resulting physical sheets through both public builders.

## §1. Producers, receivers and evaluation order

1. Preserve the declaration at sheet parse. In elidex-css, parser.rs collects Stylesheet.page_rules. page.rs currently extracts the first parseable size separately and rebuilds page properties from values. Carry ordered declarations, priority, selector alternative and the originating sheet’s grammar context through this boundary. Use T’s BuiltIn or owned registry snapshot and G’s length grammar. Parse the complete optional selector prelude against CSS Page §4.3 before compiling alternatives. An omitted prelude matches all pages. A valid named alternative retains its name and cannot match an unnamed page. An invalid member invalidates the entire list and rule. Compile only complete alternatives and preserve the specified margin-box declarations. Nested conditional page rules retain their existing scope under #11-css-media-conditional-side-rules.
2. Prepare candidates in elidex-style. Compute page specificity once per selector alternative (page name, first/blank count, left/right count) and attach it to each candidate with the originating cascade tier, importance and stable sheet/rule/declaration order. Reuse T’s ordering machinery with this page-specific tuple at the specificity comparison. Rank size, each margin longhand, font-size and custom properties by the same ordering. Preserve each winning longhand’s pending shorthand and receiving context. A selector list contributes the priority of its most specific matching alternative.
3. Use one immutable snapshot of the run’s sheets and UA target geometry in build_paged_pipeline. Remove the independent authored rule list from the shell input. Preserve the UA sheet and default margins as device configuration. Evaluate print media conditions against the UA target sheet; a selected first-page size cannot change which document media rules match. Prepare root inheritance inputs with the UA default page area as the viewport reference for dependencies that feed page geometry. Keep this intermediate root evaluation private to the pass. It supplies the immutable root computed custom-property map and the root font reference for page calculations.
4. For each supported page selector combination, overlay the winning page custom properties on that root map and resolve them with T. Evaluate the page font relative to the root font. Resolve size using page em, root rem and the UA area for geometry-dependent viewport units. Then evaluate margins against the selected sheet width/height and page font. For a first-page margin whose viewport unit would help define the document viewport, use the same UA area. This cycle-breaking reference is the engine choice recorded under PM 1001. Pass resolved numeric inputs to a pure geometry evaluator in the dependency-neutral layer. Keep CSS parser dispatch and variable resolution in CSS/style. Store sheet, margins, content extent and origin together. The selection input is page identity plus blankness; the later paginator supplies both.
5. Select the first page area and apply document style using that initial containing block for every page. Publish the final ComputedStyle on the document entities. Keep the media-query reference independent in the style walk. Subsequent pages use the same snapshot of geometry dependencies; never feed the final document root font back through the first-page computation. On new sheets, root style or UA geometry, run preparation again before handing the prepared result to the shell’s paged entry. Each run owns its inputs, with no entity-keyed side cache. Switch both existing effective size and margin readers to the common evaluation path and remove the parse-time unit converter and selector-count sorting.

6. After final document style publication, pass G’s existing margin-box producer the original specified margin-box declarations and an immutable record of the selected page font, final document root font and first-page area. G alone resolves these to the px inputs for both builders. Rebuild from specified declarations when the run changes. In the real-entry fixture below use margin-box padding-left:1rem and padding-right:10vw. Read the prepared inputs delivered downstream on both runs (2.24px and 11.2px, then 4.24px and 21.2px). Confirm the source sheet retains 1rem and 10vw across both runs.

### Margin-box font handoff after the builder split (PM 1067 and 1070)

**PM 1067 — Select the page font before resolving inherited margin-box lengths.** Use one unqualified rule containing `@top-left { content: "1"; padding-left: 1em; text-align: left }` and a page font of 20px. A separate `@page :first { font-size: 40px }` changes only the selected page font. CSS Page 3 §6 makes the page context the inheritance source for the margin box. For each page identity supplied to 3b.1, combine matching declarations for that margin-box position, inherit from that identity’s computed page font and pass the winning specified values to G’s existing resolver. Assert one prepared top-left box per page, with padding-left 40px on page one and 20px on page two. Verify the source declaration still contains 1em. This exercises the same unqualified box on both pages even though a different rule supplies the first page’s font.

**PM 1070 — Preserve a computed zero through painting.** Exercise both `font-size: 0in` and `font-size: 0px` on a top-left box containing a digit, a colored background and a visible border. Check the prepared font is 0px in both cases, then exercise the existing margin-box painter through both public builders. Emit the same background and border rectangles in the same positions for both inputs and no glyph command for that box. A positive-size control with the same font, content and decorations must emit its glyph. In `builder/paged.rs`, distinguish an explicit zero from a missing size when resolving paint inputs and retain decoration painting before the zero-size text path. This closes G’s observed fallback to the local 12px default.

3b.1 verifies both font selections at the style-to-layout handoff using supplied page identities. Carry the selected context with its entry in the 3b.3 page plan and with its corresponding fragment during replay. In 3b.4 run the PM 1067 two-page fixture through both public builders. Compare glyph x positions with explicit 40px and 20px padding controls at the same page-local origin and require exactly one top-left text command on each page. Replay the PM 1070 decoration and glyph assertions there as well.

### Receiving grammars and controls

- Size consumes one or two nonnegative lengths, auto, or supported named paper and optional orientation in either order. Keep bare portrait/landscape on the UA target. Require exhaustion. A square with calc(1in + 12pt) has side 112px. Compare a rectangle, an extra term, a trailing percentage, an unknown unit after a valid prefix, negative literals and both rejected length/orientation orders. Earlier valid declarations survive later invalid syntax. A negative calculation clamps to zero at evaluation. Use G’s category and range handling for direct and substituted input.
- Reparse a winning pending size with the descriptor grammar; an invalid substitution computes to auto. Reparse a winning pending margin shorthand in its sheet’s declaration grammar, taking only the longhands it won. Invalid substituted non-inherited margins take their initial zero. Check all four sides through the selected geometry. On a 400×600 sheet, top:10% yields 60px and left:10% yields 40px. Also cover 10mm, 12pt and mixed length-percentage calc. On a 700×900 UA sheet, auto or invalid winning size yields 700×900 and bare landscape yields 900×700.
- Parse sheets A and B with distinct registry snapshots. A declares --a:2px and margin:var(--a); B declares --b:7px and margin-left:var(--b). At the production page receiving-parser call record its actual context argument in the test and associate it with the winning declaration. Check A’s snapshot for the shorthand reparse and B’s for the independent left side. Assert top/right/bottom/left = 2/2/2/7px. Rerun with A’s variable invalid, checking each call against the snapshot of its originating sheet in the new run, and assert 0/0/0/7px. Direct equivalents control the computed sides.
- Put each test rule after an unconditional size:200px. A later omitted-prelude size:300px applies generally. A later :unknown or :first, :unknown with size:1px leaves 200px even on the first page. A later invoice:first cannot match the unnamed first page. A valid invoice:first, :left with size:300px changes only matching left pages. Test an earlier :first against a later :right and an earlier :blank against a later spread selector. Vary importance, duplicate pseudo-classes, and equal-specificity source order. Exercise size, margin, variable and font winners.

## §2. Crossing checks

| Crossing | Producer → consumer | Distinguishing observation |
|---|---|---|
| Cascade × substitution | Sheet context and declaration ranks → page-local map and receivers | The first page overrides a root variable; another page inherits its root value. Invalidating only the first-page variable invalidates the winning declaration there without reviving the loser or changing the other page. |
| Cascade × viewport | Page size, font and margin winners → first area → document style | With UA width 800px and zero UA margins, select a 200px first sheet and 10px side margins. A descendant’s 10vw font is 18px even when later sheets differ. A min-width:700px print query still matches. Replace the first sheet rule with 300px and rerun the real shell entry; font becomes 28px. |
| Substitution × viewport | Root snapshot and page-local tokens → selected geometry → final root and descendant style | At build_paged_pipeline use a 1000px UA sheet with 100px UA margins on each side (800px UA area), root font 2vw, page font 1.5em, and authored margins zero except margin-left:1vw. Set first-page size via a variable to calc(1em + 1rem + 10lvw). The private root is 16px and the page font 24px. At the style-to-layout handoff assert sheet width 120px, left margin 8px and area width 112px; on the published root assert 2.24px. On a descendant assert distinct computed properties behind min-width:900px (applies) and min-width:1001px (retains baseline). Change only the first-page rule to add 100px to its size calculation. Rerun the real entry: handoff widths are 220px and 212px, margin remains 8px, final root is 4.24px and both media results persist. |
