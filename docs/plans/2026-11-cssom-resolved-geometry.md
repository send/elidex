# Resolve CSSOM geometry from the queried element

C1a follows N’s plan at da2ba4ad. It runs on the existing Dimension and FlexBasis types. It makes layout-dependent CSSOM reads observable before C1b changes layout inputs and C1c activates mixed computed fields.

## §1. Public query and geometry ownership

GetComputedStyle::invoke in elidex-dom-api currently reads ComputedStyle and calls the style-only serializer. The WPT harness uses the same projection after resolving style. Route DOM property access and geometry-dependent harness cases through one engine-independent resolved-value query. Its inputs identify the property, the target’s computed style, applicability and its current layout geometry. Use the existing entity and published screen geometry view. When binding the document for script evaluation, the rendering owner supplies an engine-independent read barrier. For a geometry-dependent property, invoke it on the already-bound session and mutable DOM before the handler borrows ComputedStyle or the screen view. Factor the style and screen layout update phases out of shell re-render: use the current cascade inputs, current animation state, viewport and layout resources, then publish the completed screen pass. Refresh unconditionally on these reads. Keep script dispatch, painting and redraw scheduling outside the barrier. Both named access and getPropertyValue on an existing computed declaration take this path. Never read a leftover LayoutBox from a prior screen generation or paginated pass. Keep geometry in its existing layout store.

For width on a rendered element to which width applies, select the used CSS width of the appropriate content or border box according to box-sizing. Return computed width for display:none, display:contents and inapplicable widths such as a non-replaced inline. For transform-origin on a rendered transformable element, resolve X against reference-box width and Y against its height using one shared local-pair operation with the untransformed reference width and height. CSSOM exposes its local offsets. Paint adds the reference rectangle’s position to those offsets when constructing its matrix. Preserve the existing supported axis and serialization semantics. Apply the height-like resolved-value rule from Transforms §4 and CSSOM §9. Flex-basis returns its computed keyword or length-percentage. Keep lower-level registry projections computed for transitions and underlying values. Preserve existing color handling, unvisited-color privacy and missing-style error behavior on the DOM path.
